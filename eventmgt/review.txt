4. Build REST Body for Folder Creation
Action: Build String
Store in: varRestBody

Pattern:
{
  "__metadata": {
    "type": "SP.Data.Case_x0020_DocumentsItem"
  },
  "Title": "{WorkflowVariable:varCaseName}",
  "FileLeafRef": "{WorkflowVariable:varFolderName}",
  "ContentTypeId": "0x0120D520",
  "FSObjType": 1
}

IMPORTANT: Get correct metadata type:
1. Navigate to: {YourSiteURL}/_api/web/lists/getbytitle('Case Documents')?$select=ListItemEntityTypeFullName
2. Copy ListItemEntityTypeFullName value
3. Replace "SP.Data.Case_x0020_DocumentsItem" with that value
5. Create Folder via REST API
Action: Call HTTP Web Service

URL: {WorkflowVariable:varSiteURL}/_api/web/lists/getbytitle('Case Documents')/items

Request type: HTTP POST

Request headers:
  Accept | application/json;odata=verbose
  Content-Type | application/json;odata=verbose

Request content: {WorkflowVariable:varRestBody}

Response content: Store in varRestResponse

Advanced:
  Request timeout: 60 seconds
  Retry count: 2

Workflow Actions
1. Check if Already Ran (Loop Prevention)
Action: Query List
List: Workflow History
Filter:
  List ID equals {Current Item:ID}
  AND Workflow Name contains "Request Feedback"
  AND Created is greater than {Common:Today} - 1 day
  AND Description contains "WORKFLOW COMPLETE"
Number of items: 1
Store count in: varAlreadyRan

Action: Run If
Condition: varAlreadyRan is greater than 0
Then:
  Action: Log to History List
  Message: "Workflow already ran today. Terminating to prevent duplicates."
  
  Action: Terminate Workflow
2. Check Case Status
Action: Run If
Condition: {Current Item:Case Status} is not equal to "Awaiting Feedback"
Then:
  Action: Log to History List
  Message: "Case status is not 'Awaiting Feedback'. Workflow terminated."
  
  Action: Terminate Workflow

Troubleshooting Guide
Issue 1: Folder Not Created
Symptoms
Workflow completes but no folder
Documents Link empty
REST API error in history
Solutions
Get Correct Metadata Type:
1. Open browser
2. Go to: [SiteURL]/_api/web/lists/getbytitle('Case Documents')?$select=ListItemEntityTypeFullName
3. Copy exact ListItemEntityTypeFullName value
4. Update workflow REST call with this value
5. Republish workflow
Check Permissions:
1. Case Documents library → Settings → Permissions
2. Verify workflow account has Contribute
3. If using app-only, check app permissions
Alternative: Manual Folder Creation:
Skip REST API, use Update Item to set link:
varDocumentsLink = varSiteURL + "/Case Documents/" + varFolderName
Issue 2: Emails Not Sending
Symptoms
Workflow completes
No emails received
No errors shown
Solutions

Check logs to verify email addresses

Increase Pause:

Action: Pause for 5 seconds (instead of 2)
